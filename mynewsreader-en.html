Key Features

Why MyNewsReader?

Built to combine local-first AI privacy with a lightweight Windows system-tray controller you can keep running effortlessly all day.

01

Ollama & LM Studio Support (One-Tap Toggle)

A unified AI abstraction layer handles both Ollama and LM Studio seamlessly. Switch providers in one tap from the browser settings and monitor live connectivity via the LED status indicator.

02

AI Summarization & Smart Duplicate Merging

Automatically condenses lengthy RSS articles into concise ~300-character summaries using your local LLM, while merging follow-up stories under the same topic in descending date order.

03

10-Language Full Localization

Automatically detects your OS display language and localizes the tray launcher, browser UI, LLM summarization system prompts, and default starter RSS feeds across 10 languages.

04

Silent Tray Residency & Auto Browser Launch

Launches the background Node.js server silently without an intrusive console window, and opens http://localhost:3001 in your default browser 3 seconds after startup.

05

Pause or resume background crawling from either the tray controller or the browser UI—changes sync within 2 seconds alongside live progress bars and filtered server logs.

Toggle Windows auto-start directly from the control panel. Right-clicking the tray icon and selecting "Exit" cleanly terminates the entire Node.js process tree, freeing port 3001 and RAM.

Smart Summarization & Deduplication

How AI Summarization & Merging Works

Even when multiple outlets cover the same breaking story, MyNewsReader keeps your timeline clean using tag matching and AI classification.

Context Optimization & Auto-Tagging

  • Smart Content Extraction: Fetches roughly 5,000–7,000 characters of article text so inference fits comfortably within a 4K context window.
  • Concise ~300-Char Summaries: Generates clear, scannable summaries in your configured language.
  • Two-Tier Tag Indexing: Extracts 2–5 title tags and 10–20 body tags simultaneously, linking them in the local SQLite database (news_reader.db).

3-Pattern Duplicate Classification

When an incoming article matches at least one title tag or 40%+ of body tags with an existing entry, the AI decides among three actions:

  • Pattern A (Skip): Treated as a near-duplicate report and skipped to avoid clutter.
  • Pattern B (Append Update): Recognized as a related follow-up with new details and appended inside the existing topic in descending date order.
  • Pattern C (New Topic): Registered as a brand-new headline when unrelated.
Setup & Usage

Requirements, Recommended Models & Setup

Built on standard Windows .NET Framework 4.8 so you can get started quickly without complex setup.

System Requirements

  • OS: Windows 10 / Windows 11
  • Launcher Runtime: .NET Framework 4.8 (built into Windows)
  • Backend: Node.js v18 or higher recommended
  • AI Engine: Ollama or LM Studio

Recommended Local LLM Models

  • Ollama: gemma4:12b, llama3.1:latest, etc.
  • LM Studio: gemma-4-12b-it, etc.
  • You can customize the Host URL, model name, and test connectivity directly from the UI settings.
1

Start Your Local LLM

Launch Ollama or LM Studio (with its local server enabled) and make sure your preferred model is ready.

2

Run MyNewsReader.exe

Download from GitHub Releases and double-click MyNewsReader.exe. Your default browser will automatically open http://localhost:3001 after ~3 seconds.

3

Browse & Manage via Tray

Select categories in the left pane to read date-sorted AI summaries. Double-click the system-tray icon anytime to open the control panel for crawl toggles, logs, and startup settings.

Notes & Changelog

Usage Notes & Changelog

Important Notes

  • How to Fully Exit: Clicking the top-right "×" button minimizes the controller to the system tray instead of stopping the server. To exit completely and free port 3001, right-click the tray icon and choose "Exit".
  • 100% Local Privacy: RSS fetching and LLM summarization run strictly on your local machine; no feed lists or reading history are ever sent to external developer servers.
