# SecreAI & Tools - 公式Webサイト

「設計：あまち ＆ コーディング：AI (Gemini)」によって制作されたフリーツール群の紹介用ランディングページ（1ページ完結型）です。

## 特徴
1. **Google AdSense 審査対応**
   - パブリッシャーID: `pub-7695104877965082` の広告タグ設定済み
   - 審査必須要件である「プライバシーポリシー」「免責事項」「十分な説明テキスト」「お問い合わせ窓口」を完全網羅
2. **多言語対応（現在は 日本語 🇯🇵 / 英語 🇺🇸）**
   - 右上の言語ボタンで瞬時に切り替え可能
   - `script.js` 内の辞書オブジェクトに言語を追加することで、将来的に中国語や他の言語も簡単に追加可能
3. **完全な静的サイト**
   - 依存パッケージなし（Pure HTML + CSS + Vanilla JS）
   - Cloudflare Pages や GitHub Pages にファイルを置くだけで即座に動作します

## ローカルでの確認方法
エクスプローラーから `d:\SecreAI_Build\website\index.html` をダブルクリックして、お使いのブラウザ（Chrome / Edge 等）で開くだけで確認できます。

## デプロイ（Cloudflare Pages の場合）
1. GitHub にこの `website` フォルダ（または専用リポジトリ）をプッシュします。
2. Cloudflare Dashboard にログインし、「Workers & Pages」>「作成」>「Pages」>「Git に接続」を選択します。
3. リポジトリを選び、ビルド設定は「なし（None）」、出力ディレクトリを「`/`」または「`website`」に設定してデプロイします。
4. 取得した独自ドメインを紐付ければ完了です！

## カスタマイズ箇所
- `index.html`：各ツールの正式名称やストアURL、リポジトリURLの差し替え
- `script.js`：英語・日本語のテキスト修正や追加言語の定義
