MyNewsReader

Ollama・LM Studio によるローカルAI自動要約＆重複統合機能を備えた、システムトレイ常駐型・多言語RSSニュースリーダー。
クラウドAPI課金や情報送信なしで、毎日の膨大なニュース収集を完全に手元のPCだけで効率化します。

無料ダウンロード (GitHub Releases) GitHub リポジトリを見る

※画像をクリックすると拡大表示されます（ローカルブラウザUI：http://localhost:3001）

Key Features

MyNewsReader の主な特徴

「ローカルAIで完結するプライバシー性」と「日常的に起動したまま使える軽快なトレイ常駐設計」を両立しています。

01

Ollama ＆ LM Studio 両対応（ワンタップ切替）

バックエンドに統一AI抽象化レイヤーを搭載。ブラウザ設定画面からワンタップで Ollama と LM Studio を切り替えられ、各プロバイダーの接続・稼働状態は LED ステータスインジケーターでリアルタイムに確認できます。

02

AI自動要約＆重複記事の自動マージ

巡回取得したRSS記事をローカルLLMが約300文字に簡潔要約。さらにタイトル・本文タグをもとに同一トピックの続報や重複記事を自動判定し、1つの見出し内に日付降順で整理します。

03

10言語フルローカライズ対応

OSの表示言語を自動検知し、ランチャーUI・ブラウザ画面・AI要約用のシステムプロンプト・言語別の初期RSSフィードまで、日本語を含む10言語へ自動的に切り替えます。

04

黒画面なしのトレイ常駐＆ブラウザ自動起動

黒いコマンドプロンプト画面を表示させずに Node.js サーバーをバックグラウンド起動。起動から約3秒後に既定のWebブラウザで http://localhost:3001 を自動的に開きます。

05

双方向リアルタイム同期＆ログコンソール

システムトレイの操作パネルとブラウザ画面間で「自動巡回の一時停止／再開」やニュース取得の進捗状況を2秒以内に相互同期。動作ログも重要メッセージのみを見やすく表示します。

06

Windowsスタートアップ＆完全クリーンアップ

操作パネルから Windows 起動時の自動実行をワンクリックで登録可能。トレイアイコン右クリック「終了 (Exit)」時には Node.js プロセスツリーを確実に終了し、ポート3001とメモリを解放します。

Smart Summarization & Deduplication

AI要約・重複記事統合の仕組み

同じニュースが複数メディアから配信されてもタイムラインが散らからないよう、独自のタグ照合＋AI判定ロジックを組み込んでいます。

コンテキスト最適化とタグ自動生成

  • 適切な本文抽出：ローカルLLMのコンテキスト4K以内に収まるよう、記事本文を約5,000〜7,000文字程度で取得します。
  • 約300文字の簡潔要約：要点が一目で把握できるよう、日本語・英語など指定言語で約300文字程度に要約します。
  • 2段階タグ紐付け：要約と同時に「タイトル用タグ（2〜5個）」と「本文用タグ（10〜20個）」をAIが生成し、SQLiteデータベース（news_reader.db）へ保存・紐付けます。

既存記事との3パターン自動判定

データベース内に「タイトルタグが1つ以上一致」または「本文タグが40%以上一致」する既存トピックが見つかった場合、AIが以下の3パターンから自動判定します。

  • パターン A（スキップ）：ほぼ同一内容の重複記事と判断し、タイムラインへの重複登録を回避します。
  • パターン B（続報追記）：関連記事だが新たな情報を含むと判断し、既存見出しの内部へ日付降順で追記・統合します。
  • パターン C（新規登録）：関連性がない別ニュースとして、新しい見出し・トピックを作成します。
Setup & Usage

動作環境・推奨モデル・導入手順

Windows 標準の .NET Framework 4.8 上で動作する軽量ランチャーを採用しており、複雑な環境構築なしで始められます。

動作環境

  • 対応OS：Windows 10 / Windows 11
  • ランチャー基盤：.NET Framework 4.8（Windows標準搭載）
  • サーバー環境：Node.js v18 以上推奨
  • AIエンジン：Ollama または LM Studio

推奨ローカルLLMモデル例

  • Ollama：gemma4:12b、llama3.1:latest など
  • LM Studio：gemma-4-12b-it など
  • ※設定画面から使用する Host URL やモデル名を自由に変更・テストできます。
1

ローカルLLMを起動する

お使いのPCで Ollama または LM Studio（ローカルサーバー有効化）を起動し、要約に使用したいモデルを準備します。

2

MyNewsReader.exe を起動

GitHub Releases からダウンロードし、MyNewsReader.exe をダブルクリックします。約3秒後に既定ブラウザで http://localhost:3001 が自動で開きます。

3

ニュース閲覧とトレイ操作

ブラウザの左ペインでカテゴリを選択し、要約された記事を日付順に閲覧できます。トレイアイコンをダブルクリックすると巡回制御・ログ確認・スタートアップ登録用の操作パネルが開きます。

Notes & Changelog

使用上の注意点・更新履歴

ご利用上の注意・FAQ

  • アプリの完全終了方法：操作パネル右上の「×」ボタンは誤終了を防ぐため「システムトレイへの最小化」として動作します。完全に終了してポート3001を解放したい場合は、トレイアイコンを右クリックして「終了 (Exit)」を選択してください。
  • プライバシーと通信先：RSS取得とローカルLLMへの要約リクエストはすべてご自身のPC環境内で完結します。購読フィードや閲覧履歴が開発者サーバーへ送信されることはありません。
