OBS Studio Browser Source Setup Guide

Exact configuration instructions directly from the official GitHub README ("5. OBS Browser Source Setup"). Loading subtitles as a browser source renders clean, hardware-accelerated text with typewriter animations.

Official Setup

OBS Studio Browser Source Configuration Table

  1. Launch OBS Studio.
  2. In the Sources panel, click "+" > "Browser" to add a new browser source.
  3. Configure the properties window exactly as follows:
Setting Item Config Value
Local file [Check / Enable]
File path <SubtitLocar Directory>\frontend\subtitle.html
Width 1920
Height 1080
Custom CSS (Leave Blank)
Shutdown source when not visible [Check / Enable]

4. Click "OK" to save.
Once SubtitLocar is running, subtitles are pushed via its local WebSocket server (port 8765) and rendered automatically onto your stream canvas with smooth typewriter animations.

Desktop Subtitle Overlay Guide

Floating subtitle feature for games and movies without needing broadcasting software.

Feature 1

Click-Through Transparency

Check "Overlay translated subtitles on game screen" to float subtitles on top. Mouse clicks pass directly through to your game window, completely preventing accidental input.

Feature 2

Draggable Position Adjustment

Check "Adjust subtitle position (allow drag)" to temporarily unlock and reposition the frame anywhere. Position coordinates auto-save to settings.json, returning to click-through mode when unchecked.

Feature 3

Dynamic Styles & Opacity

Instantly toggle between text-only or semi-transparent backgrounds, adjust frame width (Small 35% / Medium 50% / Large 70% with automatic font scaling), and set opacity (0%, 30%, 60%).

Recommended Hardware Specs & Lightweight Model Guide

When streaming games with OBS on the same PC, choosing a lightweight LLM model with low VRAM footprint and compact context overhead is essential for zero lag (November 2026).

Entry Setup

GPU VRAM 4GB - 6GB / GTX 1660, RTX 3050, 4050, etc.

Supported STT (Faster-Whisper)
small

Lowest VRAM footprint, minimizing speech recognition latency with zero overhead.

Recommended LLM (Ultra-Lightweight)
1.5B - 2B Class (Q4_K_M)

Model Examples: Qwen 3.5 2B, Gemma 4 2B

Game Streaming & Context Overhead:
Best for lightweight indie games and 2D titles. Selecting the "small" STT model with an ultra-lightweight 1.5B-2B LLM delivers instant subtitles without eating into critical GPU memory.
Sweet Spot Recommendation

Mid-Range Setup

GPU VRAM 8GB - 12GB / RTX 3060, 4060, 4060 Ti, etc.

Supported STT (Faster-Whisper)
large-v3-turbo (or small)

High transcription precision with accelerated inference speed. The golden choice for game streamers.

Recommended LLM (Fast Translation Focus)
2B - 4B Class (Q4_K_M)

Model Examples: TranslateGemma, Qwen 3.5 4B, Gemma 4 4B

Game Streaming & Context Overhead:
The ideal sweet spot for streaming popular 3D titles (Apex, VALORANT, Genshin, etc.). Pairing the fast "large-v3-turbo" with specialized lightweight translation models like TranslateGemma or Qwen 3.5 4B reserves 6-8GB VRAM for games, preventing FPS drops and context queue bottlenecks entirely.

High-End Setup

GPU VRAM 16GB+ / RTX 4070 Ti S, 4080, 4090, Multi-GPU, etc.

Supported STT (Faster-Whisper)
large-v3-turbo / large-v3

Top-tier speech transcription accuracy across noisy environments, loud game sound effects, and fast speech.

Recommended LLM (High Precision & Long Context)
4B - 7B / 12B Class (Q4_K_M - Q6_K)

Model Examples: TranslateGemma, Gemma 4 12B, Qwen 3.5 7B

Game Streaming & Context Overhead:
Runs demanding AAA games at ultra settings while streaming with zero strain. Handles wider context windows for natural nuance, even with simultaneous SecreAI ChromaDB vector queries running.
