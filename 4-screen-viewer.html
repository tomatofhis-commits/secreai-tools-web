4 Screen Viewer

1つのブラウザタブ内で最大4つの動画を同時に並べて視聴できるマルチ画面動画ビューア。
v1.4.0 で 4種類の柔軟なレイアウト切替 と 省メモリ Lite (Embed) モード を搭載し、YouTube・ニコニコ動画・Twitch・Vimeo などを快適かつ低負荷に同時再生できます。

Developer's Note

開発の背景と設計思想 ― 低負荷で途切れない多視点視聴を実現するために

コラボ配信や大会中継、複数のニュース番組を同時に追いたいとき、ブラウザのウィンドウを手動で4つ並べてサイズ調整し、タブを行き来しながら管理するのは大きな手間がかかります。4 Screen Viewer は、拡張機能のアイコンを1回クリックするだけで専用ビューアを開き、1つのタブ内で複数動画をスマートにまとめられるよう開発しました。

一方で、ブラウザ上でYouTube動画を4つ同時に開くと、各フレームが裏側でライブチャットやコメント欄・関連動画のスクリプトを読み込み続け、メモリ消費が急激に膨らむ課題や、逆に軽量な埋め込みプレイヤーでは配信側の制限で「エラー 152-4」が出て再生できない課題に直面します。

そこで v1.4.0 では、declarativeNetRequest による埋め込み時 Referer 最適化と省メモリな Lite (Embed) モード を標準搭載しつつ、制限動画に出会った瞬間だけワンクリックで 通常（Watch）モード へ切り替えられるハイブリッド方式を採用しました。さらに非表示フレームの完全破棄や重い裏処理DOMの物理削除を組み合わせることで、「軽さ」と「再生の確実性」の両立を追求しています。

Key Features

主な機能と技術的メリット

マルチ視聴の使いやすさだけでなく、長時間視聴でもブラウザが重くなりにくい省メモリ設計と安全性を細部まで作り込んでいます。

4種類の柔軟なレイアウト切替

4 Grid (2x2)・2 Side (1x2)・1 Main + 2 Sub・1 Main + 3 Sub の4パターンをワンクリックで切り替え可能。選択した構成は自動保存され、複数ウィンドウを並べる手間なく1タブ内で常に理想の視聴画面を再現できます。

省メモリ「Lite (Embed)」＆通常モード切替

標準ONの Lite (Embed) モードは軽量な埋め込みプレイヤーを使用し、Referer最適化ルールによりエラー152-4を抑えながら通常ページ再生と比べてメモリ消費を約30〜40%規模まで削減します。投稿者が埋め込み禁止にしている動画に当たった場合も、チェックを外すだけで即座に通常（Watch）モードへ切り替えて視聴を継続できます。

不要DOM削除＆フレーム破棄の軽量化設計

親タブ起動直後に window.stop() で元ページの重いスクリプト読み込みを遮断し、各枠はURL読み込み時にのみ動的生成します。Clear やモード切替・レイアウト縮小時には古い iframe を about:blank 遷移後にDOMから完全破棄。さらに通常モード使用時でもライブチャットやコメント欄・関連動画DOMを物理削除し、自動再生補助タイマーも再生確認後に停止してメモリ膨張を防ぎます。

主要動画サイト＆汎用埋め込みの自動URL変換

普段ブラウザで見ている通常URLを貼り付けるだけで埋め込み用URLへ自動変換します。YouTube（通常・youtu.be・/live/）、ニコニコ動画、Twitch（チャンネル配信・アーカイブ・クリップ）、Vimeo に加え、HTMLの <iframe src="..."> タグからのURL自動抽出にも対応しています。

1クリック起動・Enter即再生・没入ダークUI

ツールバーの拡張機能アイコンを押すだけで新しい専用ビューアタブが即起動します。URL入力欄に貼り付けて Enter キーを押すだけですぐに読み込みが開始され、無駄な余白やヘッダーを排した黒背景（#0f0f0f）のシアター表示で映像に集中できます。

通常タブ無干渉＆ローカル完結の安全設計

最新の Manifest V3 に準拠し、ヘッダー調整ルールは sub_frame 等の専用条件に限定しているため、通常のブラウザタブで開いているYouTubeのチャットやセキュリティ動作に干渉しません。入力したURLやレイアウト設定もすべてブラウザ内の localStorage でのみ管理され、外部サーバーへの送信は一切行われません。

How to Use

使い方ガイド（4ステップ）＆操作リファレンス

インストール後、複雑な初期設定は不要です。アイコンをクリックしてURLを貼るだけですぐに多画面視聴を始められます。

STEP 1

拡張機能を追加

Chrome ウェブストアから「4 Screen Viewer」をワンクリックで Google Chrome に追加します（無料）。

STEP 2

専用ビューアを起動

ブラウザ右上の拡張機能アイコンをクリックすると、マルチ画面ビューア専用の新しいタブが開きます。

STEP 3

レイアウトとモードを選択

上部のメニューから 4 Grid (2x2) や 1 Main + 3 Sub 等のレイアウトを選択します（Lite (Embed) は標準でON）。

STEP 4

URLを貼って同時再生

各枠の入力欄（URL 1〜4）に動画URLを貼り付け、Load ボタンまたは Enter キーで同時再生を開始します。

コントロール要素 役割 動作の詳細・活用のコツ
URL 1 〜 URL 4 / Load 動画URL入力と読み込み 対応サイトの通常URLや <iframe> コードを貼り付け、Load ボタンまたは Enter キーで再生を開始します。既に再生中の枠へ別URLを読み込む際は、古いフレームを完全破棄してから再生成します。
Clear 個別スロットの終了 対象スロットの入力欄を空にし、中の動画フレーム（iframe）をDOMから破棄してメモリを解放します。見終わった枠だけを止めたいときに便利です。
Lite (Embed) 省メモリ / 通常モード切替 チェックONで省メモリな埋め込み再生、OFFで通常ページ再生（エラー152-4回避用）に切り替わります。切替時は表示・再生中の全スロットを新モードで自動再読み込みし、設定は保存されます。
Layout セレクト 4種レイアウト切替 4 Grid (2x2) / 2 Side (1x2) / 1 Main + 2 Sub / 1 Main + 3 Sub を切り替えます。縮小時に隠れたスロットはフレーム破棄され、URL文字列のみ保持されます。
Clear All 全スロット一括リセット 表示中の全スロットのURL入力欄をクリアし、すべての動画フレームを一括破棄します。次の配信グループへ丸ごと入れ替える際に役立ちます。
Back to YouTube ビューアモード終了 URLの 4screen パラメータを解除し、通常のYouTubeトップページへ戻ります。

FAQ & Troubleshooting

よくある質問とトラブルシューティング

ご利用時につまずきやすいポイントや、安全面・メモリ仕様についての疑問にお答えします。

Q1. YouTubeで「エラー 152-4」や「再生できません」と表示された場合は？

動画の投稿者側が「外部サイト等への埋め込み再生」を無効化している場合、Lite (Embed) モードではエラーが表示されることがあります。その場合は上部コントロールバーの Lite (Embed) のチェックを外してOFF にしてください。通常ページ方式（Watchモード）に切り替わり、埋め込み制限動画でも再生できるようになります。

Q2. 別の枠に動画を読み込むと、再生中の動画が一時停止することがあります。

ブラウザのメディア再生制御により、別フレームの自動再生が走った瞬間に既存のプレイヤーが一時停止する場合があります。再生ボタンを押して再開するか、あらかじめ再生中の動画を一時停止した状態で新しい枠の Load を行うと回避しやすくなります。

Q3. 長時間の視聴でブラウザのメモリ消費を抑えるコツはありますか？

まずは Lite (Embed) をON のまま視聴するのが最も効果的です（通常モードに比べメモリ消費を大幅削減できます）。また、3画面以下で十分な場合はレイアウトを 2 Side (1x2) や 1 Main + 2 Sub に絞ると未使用フレームが完全破棄されます。数時間以上連続再生して重く感じた場合は、その枠だけ Clear → Load し直すとフレームが作り直されてリフレッシュされます。

Q4. 通常のYouTube閲覧タブやライブチャットに影響は出ませんか？

影響ありません。background.js のヘッダー調整ルールは sub_frame 等の専用条件に限定されており、コンテンツスクリプトのUI非表示・DOM削除処理も ?4screen=1 や &subscreen=1 パラメータが付いたビューア専用画面でのみ発動します。普段お使いのYouTubeタブの動作やチャット表示はそのまま維持されます。

Q5. 入力した動画URLや視聴履歴が外部へ送信されることはありますか？

一切ありません。レイアウト設定（4screen_layout）やモード設定（4screen_lite_mode）はお使いのブラウザ内の localStorage に保存され、URL変換処理もすべてブラウザ内で完結します。運営者のサーバー等へ閲覧履歴や個人データを送信・収集する機能はありません（詳細は プライバシーポリシー をご覧ください）。

Q6. 複数画面の音声が重なって聞き取りづらいときはどうすればいいですか？

各枠は独立した動画プレイヤーとして動作しているため、プレイヤー下部の音量アイコンやミュート機能も枠ごとに個別操作できます。1 Main + 3 Sub などの構成では、左側のメイン枠だけ音声をONにし、右側のサブ枠はミュートにして映像の変化だけを監視する使い方がおすすめです。
