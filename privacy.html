プライバシーポリシー

SecreAI & Tools（https://amachi-tools.win/）における個人情報、広告・解析Cookie、および配布ソフトウェア・Chrome拡張機能でのデータ取り扱い方針です。

制定日：2026年11月9日 最終改定日：2026年11月20日

SecreAI & Tools（以下「当サイト」といいます）は、利用者の皆様の個人情報を適切に保護し、安心してご利用いただけるよう、以下のとおりプライバシーポリシーを定めます。

1. 個人情報の利用目的

当サイトでは、お問い合わせフォーム等を通じてご連絡いただく際に、お名前（ハンドルネーム等）やメールアドレスなどの個人情報をご入力いただく場合があります。

取得した個人情報は、お問い合わせに対する回答、不具合対応のためのご連絡、および必要な情報案内のためにのみ利用し、これらの目的以外で利用することはありません。また、法令に基づく開示要請がある場合やご本人の同意がある場合を除き、個人情報を第三者へ提供・開示することはありません。

2. 広告の配信について（Google AdSense）

当サイトは、第三者配信の広告サービス「Google AdSense」を利用しています。Google を含む第三者配信事業者は、利用者が当サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて、適切な広告を表示するために Cookie（クッキー）を使用することがあります。

Google が広告 Cookie を使用することにより、利用者が当サイトや他のサイトにアクセスした情報に基づき、Google やそのパートナーが利用者に適切な広告（パーソナライズ広告）を表示できるようになります。

  • 利用者は、Google 広告設定にアクセスすることで、パーソナライズ広告を無効にすることができます。
  • また、www.aboutads.info にアクセスすることで、パーソナライズ広告に使われる第三者配信事業者の Cookie を無効にすることもできます。
  • Google による広告でのデータ利用および Cookie の詳細については、Google の「広告 – ポリシーと規約」をご確認ください。

3. アクセス解析ツールについて

当サイトでは、サイトの利用状況の把握およびコンテンツ・利便性の向上を目的として、アクセス解析ツール（Google Analytics 等）およびホスティング基盤（Cloudflare Pages）の標準的なアクセス統計を利用する場合があります。

これらのアクセス解析ではトラフィックデータの収集のために Cookie 等を使用することがありますが、データは匿名で収集されており、個人を特定するものではありません。Cookie を無効にすることで収集を拒否することが可能ですので、お使いのブラウザ設定をご確認ください。

4. 当サイト配布ツール・Chrome拡張機能におけるデータの取り扱い

当サイトで紹介・配布しているソフトウェアおよび Google Chrome 拡張機能（SecreAI、SubtitLocar、TruckerWalkAround、MyNewsReader、YouTube Multi Auto Playlist、4 Screen Viewer）は、プライバシー保護とローカル完結性を重視して設計されています。

  • 運営者サーバーへの非収集：各ツールで処理される画面キャプチャ、音声入力・システム音声、AIとの会話履歴、ChromaDB のベクトルデータ、RSSフィード購読情報、視聴中の動画URLや再生リスト設定などは、すべてご利用者様のPC内またはブラウザのローカルストレージ上で保持・処理され、当サイト運営者のサーバーへ送信・収集されることはありません。
  • 外部AI API の利用時：SecreAI 等のツールにおいて、ご利用者様ご自身で Gemini API や OpenAI API 等の外部APIキーを設定して利用される場合、入力内容や画像データは設定されたAPI提供元へ直接送信されます。外部API側でのデータ取り扱いについては、各API提供事業者のプライバシーポリシーおよび利用規約をご確認ください。ローカルLLM（Ollama / LM Studio 等）のみを使用する場合は外部送信は発生しません。
  • Chrome 拡張機能の権限：YouTube Multi Auto Playlist および 4 Screen Viewer は、タブ分割・再生リスト作成など拡張機能の動作に必要な範囲でのみブラウザ機能を利用しており、閲覧履歴や個人情報を外部へ送信することはありません。

5. 外部リンク先での個人情報保護

当サイトには、GitHub、Google フォーム、Chrome ウェブストア、VirusTotal、YouTube などの外部サイトへのリンクまたは埋め込みコンテンツが含まれています。リンク先の外部サイトにおける個人情報の取り扱いやコンテンツ内容については、当サイトでは責任を負いかねますので、各外部サイトのプライバシーポリシーをご確認ください。

6. プライバシーポリシーの変更について

当サイトは、法令の改正やサービス内容の変更、広告・解析ツールの運用変更に応じて、本プライバシーポリシーを予告なく見直し・改定することがあります。改定後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。
