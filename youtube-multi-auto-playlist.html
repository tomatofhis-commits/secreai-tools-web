YouTube Multi Auto Playlist

Chromeのサイドパネル（Side Panel）で1〜4個のYouTube動画を同時にストリーミング再生。
登録チャンネルやRSSフィードから再生リストを自動生成し、日付・未視聴フィルタ、省メモリ Lite モード＆3段階メモリ解放、音量・再生速度の自動引き継ぎを備えた高機能プレイヤーです。

Chrome ウェブストアに追加する (無料) 機能・使い方を見る

画像をクリックすると拡大表示できます

Developer's Note

開発の背景と設計思想 ― 作業を止めずに「自分専用の連続視聴環境」を

調べ物やプログラミングをしながら登録チャンネルの新着動画を消化したいとき、YouTubeのメインタブを何度も行き来したり、動画が切り替わるたびに再生速度や音量を調整し直したりするのは意外と大きなストレスになります。YouTube Multi Auto Playlist は、ブラウザのサイドパネルに1〜4画面と再生キューを常駐させ、作業を邪魔せずに動画を自動巡回させる目的で開発しました。

しかし、サイドパネル内で動画を次々と自動再生し続けると、古いプレイヤーのメモリが解放されず重くなる問題や、ページ取得だけでは大量チャンネルの新着を素早く集めにくい問題が見えてきました。

そこで v1.2.0 では、動画終了時に「動画リソース解放（releaseVideo）→ iframe の破棄 → 新規生成」を行う 3段階メモリ解放リセット と順次 ロードキュー制御 を導入し、さらに最大2,000件のローカルアーカイブを持つ RSS一括取得機能 や 音量・再生速度の自動引き継ぎ を実装しました。軽快さと実用性を両立した、毎日使える連続再生ツールを目指しています。

Key Features

主な機能と技術的メリット

1〜4画面のマルチ表示からRSSによる自動リスト構築、長時間連続再生に耐える3段階メモリ解放までを一つのサイドパネルに凝縮しています。

サイドパネルで1〜4画面切替＆高さリサイズ

Manifest V3 の sidePanel API により、アイコン1クリックでサイドパネルを起動。1 Screen〜4 Screens を即座に切り替えられ、非表示になった枠は自動停止します。下部のプレイリスト（Queue）領域は境界をドラッグして高さを自由に調整できます。

ページ取得＆RSS一括収集（最大2,000件保存）

開いているYouTubeページから動画一覧を取得する Get Videos（途中停止用 Stop 付き）に加え、+ Ch でチャンネルを登録し RSS ボタンから5件ずつのバッチ処理で高速一括取得が可能。取得データは最大2,000件のローカルアーカイブへ自動マージされます。

日付・アンカータイトル・未視聴フィルタ＆ソート

折りたたみ可能なフィルタ行から、指定日以降の抽出（From:）、特定タイトルまでの絞り込み（Anchor title）、未視聴のみ（Unwatched）の抽出に対応。取得順やタイムスタンプに基づく昇順（▲）・降順（▼）ソートや、Clear Played による再生済み整理もワンクリックです。

自動連続再生＆音量・再生速度の自動引き継ぎ

Auto スイッチをONにすると動画終了（ended）を検知して3秒後に次の動画を自動再生します。さらに volumechange / ratechange を監視して設定を保存するため、次の動画へ切り替わっても好みの音量・ミュート状態・再生速度がそのまま引き継がれます。

省メモリ Lite モード＆3段階メモリ解放リセット

標準ONの Lite モードでは軽量な /embed/ プレイヤーを使用（Referer最適化でエラー152-4を回避）。埋め込み制限動画はOFFで通常Watch表示に切替可能です。さらに動画終了ごとに「releaseVideo 解放 → iframe 破棄 → 再生成」の3段階リセットとロードキュー制御を行い、メモリ蓄積を抑えます。

通常タブ無干渉＆ローカル完結の安全設計

declarativeNetRequest のヘッダー調整はサイドパネル内の sub_frame 等に厳格限定されているため、通常のYouTubeタブやライブチャットに影響しません。動画リスト・RSSチャンネル・アーカイブ・再生設定はすべて chrome.storage.local に保存され、外部送信は一切行われません。

How to Use

使い方ガイド（4ステップ）＆操作パネルリファレンス

インストールからプレイリスト作成・連続再生まで、直感的なサイドパネル操作ですぐに始められます。

STEP 1

拡張機能をインストール

Chrome ウェブストアから「YouTube Multi Auto Playlist」をワンクリックで追加します（無料）。

STEP 2

サイドパネルを開く

ブラウザ右上の拡張機能アイコンをクリックすると、右側に専用のサイドパネルが開きます。

STEP 3

動画リストを作成・絞り込み

YouTubeの登録チャンネル等で Get Videos を押すか、+ Ch → RSS で取得し、日付や Unwatched で絞り込みます。

STEP 4

画面数・Lite・Auto を選んで視聴

1〜4 Screens、省メモリ Lite、自動再生 Auto を好みに合わせて設定し、快適な再生を開始します。

操作メニュー番号付きガイド（[1]〜[12]）

目的別：動画リストの獲得手順（番号ガイド）

上の番号付きメニュー（[1]〜[12]）を使った、代表的な3つのリスト作成パターンです。

パターン 1：特定チャンネル・プレイリスト

日付などを指定せず、そのまま全リストを獲得する方法

1. 取得したいYouTubeチャンネルの「動画」タブ、またはプレイリストのページを開きます。
2. [1] でオプション行を開き、[8] From:（右隣の × でクリア）と [9] Anchor title が空になっていることを確認します（未視聴のみにしたい場合は [10] Unwatched をON）。
3. [2] Get Videos をクリックすると、開いているページの動画一覧が自動でリストに追加されます。必要に応じて [3]（▲ / ▼）で並べ替え、[4]〜[6] で画面数・Lite・Auto を選んで再生します。

パターン 2：お気に入りチャンネル × 日付指定

お気に入りチャンネルを指定日付までさかのぼって全部入れる方法

1. YouTubeの「登録チャンネル」ページ（youtube.com/feed/subscriptions）を開きます。
2. [1] を押してオプション行を展開します。
3. お気に入りチャンネルをRSSで一括収集したい場合は、チャンネルページで [11] + Ch を押して登録します（登録件数が [12] に表示されます）。
4. [8] From: にさかのぼりたい開始日（例：2026/10/06）を入力します（未視聴のみなら [10] もON）。
5. [2] Get Videos（RSS登録済みなら [12] RSS）をクリックすると、指定した日付以降の動画がすべてリストへ自動収集されます。

パターン 3：動画タイトル指定（アンカー）

動画名を指定して、そこまでさかのぼったリストを獲得する方法

日付指定（[8]）でうまくリストを獲得できない場合でも、目印となる動画タイトルを指定しておくことで、その動画の手前まで確実にリストを獲得できる機能です。
1. YouTubeの「登録チャンネル」ページ（または対象のチャンネルページ）を開きます。
2. [1] でオプション行を開き、日付指定が不要な場合は [8] の右隣の × ボタンで日付をクリアします。
3. [9] Anchor title に、さかのぼりの目印にしたい動画タイトル（前回最後に視聴した動画名やその一部など）を入力します。
4. [2] Get Videos（RSS登録済みチャンネルなら [12] RSS）をクリックすると、最新動画から [9] で指定した動画に到達するまでさかのぼってリストを獲得できます。

番号 / UI要素 機能 動作の詳細・活用のコツ

おすすめの活用シーン＆姉妹ツールとの使い分け

推奨: 1 Screen / Auto ON / Unwatched ON

登録チャンネルの未視聴動画をラジオ感覚で消化

Unwatched と From: フィルタでまだ見ていない新着動画だけを抽出し、1 Screen ＋ Auto ON で連続再生。設定した倍速や音量を維持したまま、メイン画面での作業中に自動で消化できます。

推奨: + Ch / RSS / Lite ON

よく見るチャンネルを + Ch で登録しておけば、毎回登録チャンネルページを開いてスクロールしなくても RSS ボタン1つで最新動画を高速収集できます。

推奨: 2〜4 Screens / Lite ON

サイドパネルでの小規模マルチ配信チェック

メインのブラウザ画面で記事やSNSを見ながら、右側のサイドパネルで2〜4つのライブ配信や解説動画を同時表示。省メモリ Lite モードにより狭いサイドパネルでも軽快に動作します。

推奨: 1 Screen / 再生速度維持

技術講座・語学動画のながら学習

1.5倍速や2倍速で技術解説動画を連続再生したい場合でも、次の動画へ切り替わるたびに速度が自動復元されるため、キーボードやマウスを動画側へ持ち替える手間がありません。

FAQ & Troubleshooting

よくある質問とトラブルシューティング

連続再生時の挙動やRSS取得、メモリ最適化、プライバシー保護に関する疑問にお答えします。

Q1. YouTubeで埋め込みエラー（152-4など）が表示された場合は？

投稿者側で外部埋め込みが禁止されている動画の場合、Lite モードでは再生できないことがあります。その場合は上部バーの Lite のチェックを外してOFF にしてください。通常のWatchモード（シアター全画面表示）に切り替わり再生できるようになります。

Q2. 次の動画に切り替わったとき、音量や再生速度は維持されますか？

はい、維持されます。拡張機能内のスクリプトが volumechange と ratechange を監視して chrome.storage.local に保存しているため、次の動画が読み込まれた際に自動で前回の音量・ミュート状態・再生速度が復元されます。

Q3. Get Videos と RSS 機能はどのように使い分ければよいですか？

今開いている登録チャンネルや特定チャンネルの動画一覧からすぐリストを作りたいときは Get Videos が手軽です。一方、決まった複数チャンネルの新着を毎回素早く集めたい場合は、+ Ch で登録しておき RSS ボタンで一括取得する方が高速で安定しています。

Q4. 長時間連続再生しているとブラウザが重くなりませんか？

Lite モードをONにしておくことでベースメモリ消費を抑えられるほか、動画終了ごとに「動画リソース解放（releaseVideo）→ iframe 破棄 → 再生成」の3段階リセットを実行しているため、長時間視聴でもメモリが溜まりにくい設計になっています。

Q5. 通常のYouTube閲覧タブやライブチャットに影響はありませんか？

ありません。background.js のヘッダー調整ルールは sub_frame 等に限定されており、コンテンツスクリプトのUI非表示・DOM削除処理もサイドパネル内のプレイヤーフレームでのみ動作します。通常のYouTubeタブはそのままお使いいただけます。

Q6. 取得した動画リストやRSSチャンネル情報は外部へ送信されますか？

一切送信されません。プレイリスト・RSS登録チャンネル・最大2,000件のアーカイブ・再生設定はすべてお使いのブラウザ内の chrome.storage.local にのみ保存されます（詳細は プライバシーポリシー をご覧ください）。
